# reality-check-portfolio
AI-powered political media transparency tool built collaboratively with AIS UTD.

Project Demo
https://youtu.be/-ufTopMDQIc

Overview

Reality Check explores how AI can help people better understand political content on social media. It analyzes video transcripts to identify sentiment and highlight different parts of a video, helping users explore how political messages are presented.

Key Features

YouTube video transcript extraction
Transcript chunking for sentiment analysis
Sentiment classification into positive, negative, and neutral categories
Identification of the most positive, negative, and neutral sections of a video
JSON-based output to share analysis results across the team

Tech Stack
Frontend and Design: React, Figma
AI/ML: Hugging Face Transformers, RoBERTa
Data Processing: Python, YouTube Transcript API
Data Exchange: JSON

My Contributions

Transcript Processing and Sentiment Analysis

Identified the most positive, negative, and neutral sections of a video based on the sentiment results.
